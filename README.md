# Study Rooms

Today's ETH Zürich room schedules from 08:00 to 20:00. Green means unbooked,
red means booked or closed, and gray means unavailable. An **All day** badge
marks rooms with no scheduled bookings throughout that window. **Candidate**
marks rooms unbooked from 09:00 to 17:00 when they aren't free all day.

The full timetable fits on mobile, and dark mode follows your device setting.

## Run locally

Requires Node.js 22.12+ and npm.

```sh
npm ci && npm run dev
```

Open **http://127.0.0.1:5173**. Reload the page to update schedules.
Stop the servers with Ctrl+C before starting another copy.
